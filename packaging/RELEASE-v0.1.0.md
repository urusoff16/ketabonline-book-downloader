Первый установщик KetabOnline Book Downloader для Windows 10/11 x64.

- Скачайте **KetabOnline-Setup-0.1.0-x64.exe** в Assets и запустите установку.
- Python включён. Интерфейс: русский, English, العربية, Türkçe; три темы оформления.
- Настройки и загруженные книги сохраняются в `%LOCALAPPDATA%\KetabOnlineDownloader\`.
- Программа поддерживает тестовую выборку, продолжение загрузки, проверку и экспорт.
- PDF OCR не входит в установщик; инструменты доступны в исходниках.

Файл не подписан сертификатом издателя. Windows может показать предупреждение
о неизвестном издателе. SHA-256 находится в SHA256SUMS.txt.

Проверено на текущем Windows-компьютере: установка, запуск GUI, передача журнала,
штатное удаление пробной установки, тестовое скачивание 21 страницы упакованным
загрузчиком. Все 31 модульный тест прошли. Отдельная чистая Windows-машина
без установленного Python не использовалась для проверки.

Windows x64 installer. Python is bundled. The file is unsigned; see SHA256SUMS.txt.
Download the setup executable from Assets, install, and launch from the Start menu.
